# Проверка разметки и перехода на основной домен — 26 октября 2026

Проверены текущий код, публичные HTTP-ответы старого и нового сайтов,
106 уникальных URL из старого sitemap и их соответствие маршрутам Laravel.
Сервер и настройки хостинга не изменялись. Ранее подготовленные изменения SEO
остаются локальными: результаты рабочего сайта ниже относятся к опубликованной версии.

## Структурированная разметка

В шаблонах нового сайта нет JSON-LD или разметки schema.org для Product,
BreadcrumbList и Organization. Визуальные хлебные крошки есть, но структурированные
данные из них не формируются. На проверенных опубликованных главной и контактах
нового сайта JSON-LD также отсутствует.

Остаётся реализовать:

- Product на карточке: название, фотографии, описание, производитель и Offer
  с фактическими ценой, валютой, наличием и основным URL. Для нулевого остатка
  нельзя заявлять наличие товара; оценки и отзывы без исходных данных не добавлять.
- BreadcrumbList, соответствующий видимой цепочке разделов.
- Organization / подходящий тип магазина с подтверждёнными адресом, телефоном,
  названием и основным адресом сайта.
- Проверки JSON, соответствия видимым данным и ссылок на `https://autobagaz.ru`.

## Старые URL

Источник: `https://autobagaz.ru/sitemap.xml`, получен 26 октября 2026 года.
Исходный список сохранён рядом в `2026-10-26-legacy-sitemap-urls.json`.

Из 106 URL только 5 имеют соответствующий маршрут в текущей новой версии:
`/`, `/contacts`, `/prokat`, `/autobagazhniki`, `/autobox`.

приложения, а не 106 отдельных запросов к рабочему серверу.
Старый sitemap не является полной инвентаризацией: например, главная содержит
дополнительные ссылки на новости и разделы, отсутствующие в sitemap.

## Домены, HTTPS и ошибки

Запросы выполнены без автоматического следования перенаправлениям.
HTTPS-запросы прошли штатную проверку сертификатов.

| Запрос | Фактический результат |
| --- | --- |
| `https://autobagaz.ru/` | 200, старая версия сайта |
| `https://new.autobagaz.ru/` | 200, новая версия сайта |
| `http://autobagaz.ru/contacts` | 302 → `https://autobagaz.ru/contacts` |
| `http://www.autobagaz.ru/contacts` | 302 → `https://www.autobagaz.ru/contacts` |
| `https://www.autobagaz.ru/contacts` | 200, перенаправления на домен без www нет |
| `http://new.autobagaz.ru/contacts` | 302 → `https://new.autobagaz.ru/contacts` |
| `https://new.autobagaz.ru/contacts/` | 301 → `http://new.autobagaz.ru/contacts`, понижение схемы |
| `/seo-check-not-found-20261026` на обоих сайтах | 404 |
| `/autobagazhniki/seo-check-not-found-20261026` на новом сайте | 404 |
| Тот же неизвестный вложенный путь на старом сайте | 500, отдельная проблема старой версии |

Перед переключением нужно настроить постоянные перенаправления на основной
HTTPS-адрес, исключить промежуточный HTTP при удалении слеша и проверить итоговые
цепочки после настройки хостинга. Перенаправление с new на основной домен
включать при переходе; пока эти адреса обслуживают разные версии сайта.

## Защита тестового домена

Опубликованный `new.autobagaz.ru` пока отдаёт `index,follow` на главной и контактах,
а `robots.txt` содержит пустой `Disallow:`. У входа в админку есть метатег
`noindex,nofollow`, но заголовка `X-Robots-Tag` нет.
Новый `/sitemap.xml` пока возвращает 404.
Это подтверждает необходимость выкладки уже подготовленного SEO-блока
по инструкции `docs/seo.md`, а не ошибку его локальных проверок.

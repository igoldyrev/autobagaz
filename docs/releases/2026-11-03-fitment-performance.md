## Подбор автомобиля

Четыре списка товаров в `VehicleFitmentController` используют существующий
`withAvailability()`: резерв суммируется внутри запроса товаров, а повторные
обращения карточки к `available_stock` не выполняют отдельных SQL-запросов.
Доступные остатки загружаются при каждом запросе страницы, вне кеша применяемости.

`CompatibilityService::checkMany()` получает действующие исключения для группы
базовых товаров одним запросом. Фильтрация по автомобилю, активность, сроки
действия и сортировка остаются общими с одиночной проверкой. При выборе исключения
учитываются только подходящие активные Fitment. Приоритеты сохраняются:
конкретная конфигурация → конкретный Fitment → priority → последний id.
Одиночная проверка и техническая проверка пары сохраняют прежний интерфейс.

Использована изолированная копия локальной SQLite с применёнными миграциями.
Исходный локальный файл датирован 30 октября; это не свежий снимок рабочего сайта.
Те же данные перенесены в отдельный MySQL 8.4.6 без сетевого слушателя.
Проверки проходили через HTTP Kernel Laravel с отдельным кешем в памяти,
сессиями в памяти и отключённой реальной отправкой писем. Рабочая БД не менялась.
Для MySQL исходные три PHP-класса загружались из HEAD `9c2e246b` в отдельном
процессе; файлы текущего checkout для сравнения не подменялись.

Количество SQL совпало на SQLite и MySQL:

| Страница | До, холодный / тёплый кеш | После, холодный / тёплый кеш |
| --- | ---: | ---: |
| Подбор, конфигурация 1 | 156 / 100 | 43 / 30 |
| Подбор, конфигурация 7 | 210 / 154 | 75 / 62 |
| Общий каталог автобагажников | 16 / 16 | 16 / 16 |

Отдельные `SUM(quantity)` резервов сокращены с 70/92 до нуля.
На холодном подборе 44 запроса исключений заменены одним.
Каждый маршрут проверен три раза, все ответы HTTP 200. Времена локального
PHP приведены в JSON; они не являются замером загрузки рабочего сайта.

## Логотипы

Добавлены 82 WebP-варианта в `public/images/catalog/autobagazhniki/brands/thumbnails/`.
Растровые исходники преобразованы локально Pillow: RGBA, Lanczos, максимум
200×200 px без увеличения маленьких изображений, WebP quality 90 / method 6.
Вариант сохранён только при уменьшении объёма; оригиналы и SVG не менялись.
Все варианты декодируются, пропорции сохранены с учётом округления пикселей.
Визуально сопоставлены 16 самых тяжёлых исходников и их вариантов на размере
отображения 100 px; заметных изменений формы или прозрачности не обнаружено.

Шаблон использует вариант только для встроенных изображений из каталога brands
и только при наличии файла. Для пользовательского пути остаётся его изображение.
Логотип получает настоящий `src` при появлении карточки в раскрытом списке
или результатах поиска. До этого используется встроенный прозрачный GIF,
который не создаёт отдельного сетевого запроса. Повторная загрузка не назначается.

В локальном каталоге 89 карточек, включая специальные категории:

| Набор | Объём файлов, байт |
| --- | ---: |
| Все исходные изображения карточек | 1 092 448 |
| Все выбранные изображения после оптимизации | 403 497 |
| Начальные 12 карточек на компьютере | 54 328 |
| Начальные 4 карточки на мобильной ширине | 16 398 |

Это суммы размеров файлов, а не объём всего документа или замер медленной сети.
Браузерная ленивая загрузка дополнительно зависит от положения карточки.
Картинки остальных карточек не имеют внешнего `src` до их раскрытия/поиска.
Для отключённого JavaScript предусмотрены обычные изображения в `noscript`,
все ссылки марок остаются в HTML. Наличие fallback проверено тестом шаблона;
полная ручная приёмка с отключённым JavaScript остаётся в общем плане.
Используемые начертания Roboto и Roboto Slab сохранены: в существующих стилях
присутствуют веса 300, 400, 500, 700 и 900; удаление начертаний в эту работу не входит.
